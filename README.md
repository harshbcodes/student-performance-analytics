# Student Performance Analytics System

A Python-based data analysis project that analyzes student marks, grades, results, and attendance using **Python, NumPy, and Pandas**.

## 📌 Project Overview

The Student Performance Analytics System helps organize student academic records and generate useful performance summaries from a CSV dataset.

It calculates student totals and averages, assigns grades, summarizes subject performance, identifies toppers, and analyzes attendance.

## 🎯 Objectives

- Calculate total and average marks for each student.
- Assign grades using conditional statements and a reusable function.
- Identify pass and fail students.
- Calculate pass and fail percentages.
- Analyze subject-wise average, maximum, and minimum marks.
- Identify subject toppers and the class topper.
- Calculate average attendance and flag attendance records.
- Compare the highest student average in AIML and CSE departments.

## 🛠️ Technologies Used

- **Python** — programming logic, functions, and conditional statements
- **Pandas** — data loading and analysis
- **NumPy** — numerical calculations
- **Jupyter Notebook** — writing and executing the project
- **CSV** — storing student records

## 📂 Project Files

- `notebooks_project.ipynb` — Jupyter Notebook containing the project code and outputs
- `students.csv` — dataset containing student records

## ▶️ How to Run

1. Download or clone this repository.
2. Keep `students.csv` in the same folder as the notebook.
3. Open `notebooks_project.ipynb` in Jupyter Notebook or JupyterLab.
4. Ensure Python, Pandas, and NumPy are available in your environment.
5. Run the notebook cells from top to bottom to view the analysis.

## 📈 Expected Output

The project displays student totals and averages, grades, pass/fail counts and percentages, subject statistics, toppers, attendance information, and department comparisons.
